# Product direction and roadmap

Xiaolajiao explores a capability-centered form of work: people and Agents contribute to shared goals, specialists focus on work they do well, and information travels with tasks and evidence instead of repeated verbal relays.

These directions have no committed delivery dates. Planned capabilities are not current features.

| Status | Direction |
| --- | --- |
| Current collaboration features | Local accounts, shared goals, direct assignment, execution requirements, public progress, media deliverables, independent review, handoffs, capabilities and Skills, knowledge snapshots, model connections and retrospectives |
| Near-term priorities | Improve collaboration controls, traceable deliverables and capability evidence, recovery behavior and source installation |
| Provided in this delivery | Electron shell and bundled backend, with Chinese and English Windows x64 installers and corresponding source; builds and installation verified; see the [v0.1.0 release](https://github.com/lizhenjie137/intelligent-organization/releases/tag/v0.1.0) |
| Further desktop work | Improve upgrade, recovery and installation based on actual usage; automatic updates are not currently promised |
| Explore: work without a fixed office | Multi-computer and remote-team access after identity, access boundaries, encrypted transport, backup and deployment strategies are defined; access is currently loopback-only |
| Explore: business integrations | Add document, messaging or other tools according to concrete needs, with explicit authorization, execution validation and auditability; uploading a Skill does not create these integrations |

Three principles remain central: clear responsibility; delivery separate from review; and execution permission separate from capability declarations. More automation should not turn “the model says it is done” into assumed business completion.
