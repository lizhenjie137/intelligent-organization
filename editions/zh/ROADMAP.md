# 产品方向与路线图

小辣椒希望探索一种以能力与成果为中心的新办公形式：人和 Agent 围绕共同目标协作，擅长一项工作的人能专注贡献，信息随任务和证据传递，减少层层口头转述。

下列方向没有承诺完成日期；规划不代表已经具备相应功能。

| 状态 | 内容 |
| --- | --- |
| 当前协作功能 | 本机多账号、共享组织目标、直接分派、执行条件、公开进展、媒体成果、独立验收、交接、能力与 Skill、知识快照、模型连接和复盘 |
| 下一步重点 | 持续改善协作操作、可追踪的成果与能力证据、错误恢复和源码安装体验 |
| 本次已提供 | Electron 桌面外壳与内置后台，中文、英文 Windows x64 安装包及对应源码；已完成构建和安装验证，见 [v0.1.0 发布页](https://github.com/lizhenjie137/intelligent-organization/releases/tag/v0.1.0) |
| 后续桌面体验 | 根据实际使用完善升级、恢复与安装体验；当前不承诺自动更新 |
| 计划探索：无固定场地办公 | 在明确身份、访问边界、加密传输、备份与部署策略之后，支持多电脑和远程团队；目前仍限本机访问 |
| 计划探索：业务接入 | 按实际需求接入文档、消息或其他工具，逐项设计授权、执行验证与审计；上传 Skill 不自动实现这些连接 |

我们优先保持三条原则：负责人明确；交付与验收分开；执行权限与能力声明分开。增强自动化时，也不把“模型说完成”直接当作业务已经完成。
